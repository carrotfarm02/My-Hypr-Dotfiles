## DEPENDENCIES 
Requires the following packages: 

Hyprland (and all of its dependencies)

Grim, Slurp, and Satty (for screenshots)

Waybar (for the top bar)

Kitty (main terminal emulator)

Hyprpaper (for the wallpaper)

Dolphin (as the file manager)

Rofi (aplication launcher)

Dunst (notification dispatcher)

Nerd Fonts (the font library that contains the terminal font used for this config)

Optional: plugin "Gloview", by fedsfarm on GitHub.

## INSTALLATION INSTRUCTIONS
step one:

run `git clone https://github.com/carrotfarm02/My-Hypr-Dotfiles` to clone the repository

step two:

make the customizations you want (browser, or whatever) (also may be done after step 3)

step three:

move all of the files except for the README and 'Previews' folder inside the 
'My-Hypr-Dotfiles' folder into ~/.config. You can delete the afformentioned 
README and Previews file and folder respectively.
